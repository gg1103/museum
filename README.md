# 樓語 · 檔案

烛光浮雕展厅。暗房里陈列八件骑楼浮雕，鼠标是一支蜡烛——**光碰到哪里，哪里才亮**。

---

## 一、怎么看

- 移动鼠标：烛光跟随，光斑内的浮雕被照亮，其余沉在黑暗里
- 每个卡片可以拖动旋转（小幅），看清浮雕的起伏
- **点击卡片**：放大查看，可自由旋转、缩放
- 右上角「点亮全部」：整个房间点亮（手机和键盘用户也能看全）
- 键盘：`L` 点亮 / 吹灭，`Esc` 关闭放大页

**6 秒不动鼠标**，光会自己慢慢游走，画面不会全黑。

---

## 二、文件清单

上传时**全部放在同一层**，不要文件夹嵌套。

| 文件 | 作用 | 需要改吗 |
|---|---|---|
| `index.html` | 页面结构 | 不用 |
| `gallery.css` | 配色、光斑、卡片排版 | 想调风格才改 |
| `gallery.js` | 烛光跟随、放大查看 | 不用 |
| `content.js` | **所有文字** | 经常改 |
| `relief-1.glb` ～ `relief-8.glb` | 八件浮雕模型 | 换成你的 |
| `model-viewer.min.js` | 3D 组件（**必须传**） | 传一次即可 |
| `favicon.png` | 标签页图标 | 不用 |
| `og.png` | 分享缩略图 | 不用 |
| `404.html` | 网址输错时的页面 | 不用 |

---

## 三、改内容

打开 `content.js`：

- `title` / `titleEn`：标题
- `lead`：首屏那段话
- `items`：八件浮雕的**名称、编号、说明**，以及模型文件名
- `footL` / `footR`：页脚两行

想加第九件：往 `items` 里复制一段，`no` 改成 `09`，`src` 换成新模型文件名。

---

## 四、换模型

1. Blender 里导出 glTF 2.0（**glb**），勾选「应用修改器」「图像」
2. 控制体积：**6 万面以内**、贴图 **1024**，单个文件 3 MB 以内
3. 改名 `relief-1.glb` … 覆盖，或改 `content.js` 里的 `src`

原始模型几百 MB 的话，把 glb 发我，我用 Blender 压一版（减面 + 贴图降采样 + 色彩溢出）。

---

## 五、调光

`gallery.css` 顶部：

```css
--light-r: 320px;    /* 光斑半径，调大更亮更宽 */
```

暗的程度在 `.veil` 的 `opacity: 0.95`（越小越亮）；暖色强度在 `.warm` 的 `rgba(255,168,86,0.22)`。

配色在 `:root`：`--room` 房间底色、`--flame` 火焰色、`--verm` 朱红、`--ink` 文字色。

---

## 六、本地预览

双击 `start-preview.bat`（需要装 Node.js），会自动打开浏览器。

---

## 七、常见问题

**卡片是空的 / 一直转圈**
`model-viewer.min.js` 没上传，或模型文件名对不上。

**光斑跟着鼠标但画面全黑**
`veil` 的 `mask-image` 不支持。换 Chrome / Edge 最新版。

**手机上太暗**
手机端已自动关闭烛光效果，直接平铺显示。

**改完网页没变**
`Ctrl + F5` 强刷；GitHub 缓存约 10 分钟，可在网址后加 `?v=2`。
